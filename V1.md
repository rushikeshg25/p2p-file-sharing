# Direct TCP file transfer: v1

## Contract

Preserve the binary wire protocol, exact streaming, whole-file CRC and no-clobber publication; validate malformed inputs, cancellation/timeouts and end-to-end transfers.

## Acceptance

- Core operations have executable behavioral tests, including invalid input and lifecycle failures.
- Build and tests pass using the module Go version; concurrent code is checked with the race detector.
- README examples match the public API. HISTORY.md records the baseline and delivery evidence.
